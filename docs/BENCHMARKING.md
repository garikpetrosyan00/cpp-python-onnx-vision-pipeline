# Benchmarking

Benchmarking begins after both implementations pass deterministic smoke and parity checks.

The final methodology will use the same model, input, frame count, thresholds, warm-up count, CPU provider, and host. GUI display will be disabled. Capture, preprocessing, inference, postprocessing, rendering, total-frame latency, FPS, and optional RSS will be reported with explicit timing boundaries.

No placeholder number is a measured result.
